BUSINESS FACTORY 5 - سیٹ اپ

1. اس فولڈر کی یہ فائلیں اپ لوڈ کریں: app.py، brains.py، engine.py، sheets.py، store.py، requirements.txt
2. Streamlit Community Cloud پر Main file path میں app.py لکھیں۔
3. بائیں مینو (ایپ کے اوپر بائیں کونے کا >> نشان) میں API keys اور ہر slot کے "Used for" چنیں۔
4. "Make today's product" دبائیں۔ برین کام کرتے ہیں، آخر میں گیٹ کی رپورٹ آتی ہے۔
5. رپورٹ دیکھ کر "Approve and save" دبائیں۔ پھر لیپ ٹاپ، موبائل، Google ٹیسٹ فائلیں یا ZIP ڈاؤن لوڈ کریں۔
6. Google ٹیسٹ کی تین فائلیں گوگل ڈرائیو پر اپ لوڈ کر کے Google Sheets میں کھولیں اور بتائیں کون سی ٹھیک کھلتی ہے۔

اہم:
- Secrets میں keys رکھیں تو نیا کوڈ ڈالنے پر بھی keys نہیں جاتیں۔
- پروجیکٹس اور روزانہ کا ریکارڈ ایپ کے سرور پر bf5_data فولڈر میں ہیں۔ سرور ری سٹارٹ ہونے پر یہ مٹ سکتا ہے، اس لیے "Projects" ٹیب سے بیک اپ (.json) ضرور ڈاؤن لوڈ کریں۔
- ایک دن میں ایک پروڈکٹ منظور ہوتی ہے۔ دوسری کے لیے خانہ ٹِک کریں۔
- کسی پلیٹ فارم کے موجودہ قواعد اپلوڈ سے پہلے خود دیکھیں۔ یہ قانونی یا ٹیکس مشورہ نہیں۔
